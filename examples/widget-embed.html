A pretend Webook tool

This page is NOT the Tempo app — it stands in for any internal tool (e.g. an HR portal). It embeds the Global Feedback widget with the two-line snippet below. Look for the pink feedback button in the bottom-right, open it, and send a note.

<script src="https://akram-webook.github.io/tempo/widget.js"></script>
<script>window.WBK.Feedback.init({ tool: 'hr-portal', endpoint: '<proxy-url>' })</script>

Here the script is loaded from the local build (../dist/widget.js) and the endpoint points at a demo shim defined in THIS page (below) so you can see the full success flow without a live proxy. The shim is part of the example page, never part of the widget bundle.
